# Tokenizer feature request

Replace whitespace-based word counts with Flow Lexical v1, a documented deterministic source tokenizer. Count word/identifier runs, punctuation, numbers, quotes, Markdown delimiters, HTML/SVG markup and image reference source. Ignore whitespace separators. Group common emoji sequences and handle CJK characters. Raster images use deterministic non-overlapping 32×32 spatial patches, including partial edge patches. Read dimensions from bounded image headers (PNG/GIF/JPEG/WebP/BMP/ICO; browser decoding fallback for other supported formats). Unknown binary assets and unrecognized images count as one attachment token. Remote image references are tokenized as source without fetching. This is a defined spatial representation, not a model-specific vision cost or semantic embedding.

Implement exact UTF-16 spans and a streaming count; use an isolated worker with one in-flight request and latest-only coalescing. Keep search independent. Reject stale counts when editing/switching pages; cooperate with the event loop if workers are disabled. Use a compact borderless Instrument Sans metric and a 180ms numeric scramble on edits, with reduced motion and stable layout. Keep exact count accessible. Verify known token fixtures, punctuation, multilingual text, SVG, images, source coverage, cancellation, animation and a large-document benchmark. Merge only after full CI. Browser animation frame rate is not established by unit tests.
